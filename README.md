# 水豚噜噜桌面宠物

> 嗨，我是噜噜。今天也可以慢慢过，不用太着急。🍊

一只温和、慢悠悠的小水豚，住进你的电脑桌面，陪你度过工作与生活里的小小日常。

噜噜喜欢吃水果、泡澡、晒太阳，偶尔也会打个盹。你可以喂它一点好吃的，和它聊聊天，看它学习、打工、攒一点金币，再一起去便利店逛逛。忙起来的时候，噜噜也会轻轻提醒你：喝口水，休息一下吧。
